Laplace saddle + eigenframe (basis change only)
===============================================

Same Laplace saddle as FCS2 matrix Laplace:
  Q = hermite_kernel_block(μ, σ)   # single ±μ Gaussian
  V'(μ) = 0,  σ = 1/√V''(μ)

Only modification — eigenframe basis:
  Q = U Λ Uᵀ
  ỹ = (0, ε)
  G̃ from diagonal Λ (no lab A = U G̃ Uᵀ)
  V(w) = prior + ½ Σ G̃_kk φ_k²,  φ = Uᵀ c(w)

Params: d=10, N=χ=400, sa0=1, κ=0.5, ε=1

Result: the self-consistent Laplace root stays at small μ (≲0.12).
The cubic eigenvalue of that Q is tiny, so cubic learnability stays ~0.
(Deep outer wells require a multiwell/specialist Q ansatz — that is a
different theory, not "Laplace saddle + basis change only".)
